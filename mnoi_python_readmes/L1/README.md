# Требования к оформлению ЛР №1

**Тема:** поэлементные преобразования изображений.

## Подготовка
Изучить общие требования, теоретический раздел методички и выбрать изображение. Размер произвольный. Может пригодиться `numpy.cumsum` (кумулятивная сумма).

## Ограничения
Запрещены циклы и готовые стандартные функции пороговой обработки, линейного контрастирования и эквализации. Алгоритмы этих преобразований реализовать самостоятельно на NumPy.

## Задание
### I. Пороговая обработка
Реализовать поэлементное преобразование. В отчёте на экране разместить:
1. исходное изображение;
2. изображение после пороговой обработки;
3. исходную гистограмму;
4. гистограмму после обработки;
5. график функции поэлементного преобразования.

### II. Контрастирование
Реализовать контрастирование с вычислением параметров по минимальному и максимальному значениям изображения. Показать исходное и контрастированное изображения, обе гистограммы и график функции преобразования.

### III. Эквализация
Реализовать эквализацию через `np.cumsum` и визуально сравнить с эквализацией стандартной функцией Python (`skimage.exposure.equalize_hist`). Показать исходное изображение, результаты обоих вариантов, интегральные функции распределения яркости до/после, три гистограммы и график функции преобразования. Через `print` вывести массив гистограммы и границы интервалов из `hist, bins = np.histogram(...)`; продемонстрировать, что `bins` начинается с 0 и содержит 0, 1, 2, …, 255, 256 (при 256 интервалах яркости).

### Бонус
4. Реализовать пилообразное контрастирование (рис. 5 методички).
5. Реализовать все преобразования, показанные на рис. 5 методички.

## Стек
`numpy`, `matplotlib`, `skimage.io`, `skimage.exposure`.
