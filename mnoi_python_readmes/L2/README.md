# Требования к оформлению ЛР №2

**Тема:** выделение контуров.

## Ограничения и инструменты
Циклы и стандартные функции вычисления градиента, лапласиана, выделения контуров и пороговой обработки запрещены. Разрешены двумерная свёртка/корреляция и математические функции. Размер изображения произвольный. Рекомендуемые функции: `scipy.signal.convolve2d`, `numpy.sqrt`.

Если результат содержит отрицательные значения, заранее использовать тип с поддержкой отрицательных чисел. При визуализации прибавлять 128 или применять другой способ, не теряющий информацию. Плохо видимые изображения дополнительно контрастировать. В отчёте объяснить, как сохранены отрицательные значения.

## Задание
Реализовать алгоритмы на основе операторов градиента, Лапласа и двумерной свёртки:
1. метод простого градиента;
2. аппроксимацию лапласиана (маски из (20) методички);
3. оператор Прюитта (маски из (25));
4. согласование для лапласиана (маска из (27)).

Для градиентных методов показать: исходное изображение, частные производные по двум направлениям, оценку градиента, её гистограмму и бинарные контуры с подписью метода. Для методов второй производной показать: исходное изображение, оценку лапласиана, её гистограмму и бинарные контуры.

## Дополнительно (необязательно)
1. Реализовать ранговый метод.
2. Повторить на фрагменте общедоступного космоснимка (до 512×512).
3. Для сравнения выделить контуры стандартной функцией Canny.

## Стек
`numpy`, `scipy.signal.convolve2d`, `matplotlib`.
