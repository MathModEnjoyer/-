# Требования к оформлению ЛР №6

**Тема:** дифференциальное кодирование.

`x(m,n)` — исходное изображение; `y(m,n)` — уже обработанные отсчёты, совпадающие с отсчётами декомпрессированного изображения. Развёртка построчная.

## Алгоритм сжатия
1. Предсказание: `p(m,n)=y(m,n−1)`.
2. Разностный сигнал: `f(m,n)=x(m,n)−p(m,n)`.
3. Квантование равномерной шкалой: `q=sign(f)*floor((|f|+e)/(2e+1))`, где `e` — задаваемая максимальная погрешность.
4. Восстановление: `y(m,n)=p(m,n)+q(m,n)*(2e+1)`. Полученное `y` используется для предсказания следующего элемента.
5. Статистическое кодирование массива `q` и упаковку в архив реализовывать не нужно.

Алгоритм декомпрессии вывести самостоятельно из шага восстановления.

## Задание
1. Реализовать `MyDifCode(x,e,r)` → массив квантованных разностей `q`.
2. Реализовать `MyDifDeCode(q,e,r)` → декомпрессированное изображение `y`.
3. Построить график энтропии массива `q` (оценка объёма сжатых данных) от `e=0…50`.
4. На том же графике показать второй предиктор `r=2`: `p(m,n)=(y(m,n−1)+y(m−1,n))/2`.
5. Показать декомпрессированные изображения для `e=5,10,20,40`.
6. Показать разностный сигнал при `e=0`, контрастировав его для наглядности.
7. Показать квантованный разностный сигнал для `e=0,5,10`.
8. Подтвердить контроль максимальной ошибки `max(|x(m,n)−y(m,n)|)≤e` (с оговорённым правилом округления).

Работа является имитацией сжатия: вычисляются восстановленные изображения, массив квантованных значений и оценка объёма через энтропию. Циклы разрешены только в этой лабораторной; разрешены стандартные вспомогательные функции вычисления энтропии. Сам алгоритм ДИКМ реализовать самостоятельно.

## Стек
`numpy`, `matplotlib`; вспомогательные функции энтропии допускаются.
