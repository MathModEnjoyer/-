# Требования к оформлению ЛР №4

**Тема:** обнаружение объектов.

Изучить общие требования и методичку. Размер изображения произвольный. Согласованный фильтр можно не реализовывать, достаточно коррелятора. Подберите уровень белого шума так, чтобы обнаруживались не все объекты.

## Объекты и исходные изображения
Объект первого типа — буква `Т` размера 3×3. Объект второго типа — такой же шаблон в перевёрнутом виде. Подготовить три изображения: фон без объектов; фон с объектами одного типа; фон с объектами обоих типов.

## Для каждого изображения показать
1. исходное изображение фона с белым шумом;
2. фон с добавленными объектами;
3. два корреляционных поля (по одному для каждого шаблона);
4. результат пороговой обработки обоих корреляционных полей.

Коррелятор реализовать самостоятельно через двумерную корреляцию/свёртку NumPy/SciPy. Порог выбрать экспериментально и указать в отчёте. Для каждого случая описать, какие объекты обнаружены и какие пропущены.

## Стек
`numpy`, `scipy.signal.correlate2d`, `matplotlib`.
